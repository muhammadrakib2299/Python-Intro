# Python Intro & LeetCode Practice

My Python fundamentals and daily LeetCode practice — **136 LeetCode solutions** plus small scripts written while learning the language.

## What's inside

| Folder | Contents |
|---|---|
| `leetecode/` | LeetCode solutions, one file per problem, named by problem number (e.g. `10.py` = Regular Expression Matching). Covers problems 5–100 almost continuously plus selected harder ones up to #3740 |
| `Python-Intro/` | Language basics: data types, operators, conditions, loops, functions, `*args`, lambdas, comprehensions, iterators, generators, scope, exceptions, file I/O, sets/tuples/dicts |
| `Python-Intro/FreeCodeCamp/` | freeCodeCamp exercises — Caesar cipher, RPG character builder, functions |
| `Python-Intro/phitron_practice/` | Phitron course practice problems |
| `Python-Intro/lab-2/` | Small automation scripts — a console chatbot and a wallpaper changer |

## Topics practised

Dynamic programming (e.g. regex and wildcard matching), two pointers and sliding window, hashing, stacks, binary search, string manipulation, linked lists, trees and greedy algorithms.

## Run a solution

```bash
python3 leetecode/10.py
```

Most LeetCode files contain only the `Solution` class as submitted; add a quick `print(Solution().method(...))` to try one locally.
